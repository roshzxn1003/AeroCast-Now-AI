3. HOW TO LAUNCH
----------------
A. FastAPI Backend REST Server:
`source venv/bin/activate`
`cd backend && uvicorn api_server:app --host 0.0.0.0 --port 8000 --reload`
  (run from inside backend/: the service modules import each other by flat name)

B. Mobile-First React Frontend:
`cd frontend`
`npm run dev`

C. Streamlit Dashboard (Alternative UI):
`source venv/bin/activate`
`cd backend && python -m streamlit run app.py`
